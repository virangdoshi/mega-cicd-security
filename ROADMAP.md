# Roadmap

Public direction for scankit adoption and usability. See [CHANGELOG.md](CHANGELOG.md) for shipped work.

## Shipped (v1.2)

- Scan profiles (`minimal`, `standard`, `audit`, `soak`)
- Scan-only workflow (`reusable-security-scan.yml`)
- `.scankit.yml` config loader
- Optional DAST (OWASP ZAP baseline)
- Slack/Teams webhook notifications
- PR triage by category
- Demo repo, quickstart, compliance mapping

## Next

- Monorepo path-aware ecosystem detection
- Metrics badge from `security-results/latest/`
- OpenSSF Best Practices badge (in progress — see [docs/openssf-badge.md](docs/openssf-badge.md))
- GitHub Marketplace listing ([docs/marketplace.md](docs/marketplace.md))
